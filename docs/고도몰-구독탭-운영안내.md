# 고도몰 상품상세 「일시불 / 구독」 탭 — 운영·유지보수 안내 (비개발자용)

작성 2026-10-29 · 대상: 온라인사업부 · 매장 관리자 · 고도몰을 손보는 분

상품 상세페이지 위쪽에 **[일시불] [구독]** 두 칸짜리 탭이 있고, 구독 칸을 누르면
"6년 총 ○○○원 · 월 ○○원", "일시불보다 ○○원 저렴해요", 조건별 구독가, [시흥몰 가격 확인하기]·[구독 문의하기] 버튼이 나옵니다.
이 문서는 **무엇을 어디서 바꾸는지**, **잘 나오는지 어떻게 확인하는지**, **문제가 생기면 어떻게 끄는지**를 적은 것입니다.

---

## 1. 한 장 요약 — 무엇은 어디서 바꾸나

| 바꾸고 싶은 것 | 어디서 | 반영까지 |
|---|---|---|
| 구독 요금(월·총구독료), 어떤 모델이 구독 가능한지 | 자동 — DPS 수집(매일) · 직접 고칠 땐 데이터센터 관리자 › 품목 › **구독 요금 직접 관리** | 10분 안 |
| 자동납부 할인율 · 선납 할인율·한도 | 데이터센터 관리자 › 품목 › **구독 혜택 정책** | 10분 안 |
| **처음 선택되는 카드·실적 구간, 상담 신청 주소, 상담 전화** | 데이터센터 관리자 › 품목 › 구독 혜택 정책 › **기본 기준 · 상담 연락처** | 10분 안 |
| 카드 유의사항 · 카드 노출 기간 · 행사 문구 · 안내 문구 | 데이터센터 관리자 (같은 화면) · 매장 화면(store) 견적서 탭에서도 문구는 수정 가능 | 10분 안 |
| 탭 **켜기 / 끄기 / 테스트 모드** | 고도몰 관리자 › 디자인 › 스킨 파일 `goods/_sub_tab.html` 의 `enabled` 한 줄 | 즉시 |
| 탭 디자인·동작(화면 코드) | 개발 담당 (데이터센터 저장소 `sdp/sub/sub_tab.js · .css`) → 고도몰 웹FTP 업로드 | 개발 요청 |

> 핵심: **금액·문구·연락처는 고도몰에서 고치지 않습니다.** 데이터센터 관리자에서 한 번 저장하면 상품상세 구독탭, 구독센터 상세, 구독센터 목록이 **같이** 바뀝니다. 고도몰 파일은 "켜고 끄기" 용도입니다.

## 2. 구조 — 어떻게 돌아가나

```
[데이터센터 Supabase]  요금표(DPS) · 카드표 · 정책(할인율·기본 카드·상담 연락처·문구)
        │  GitHub Actions 가 10분마다(또는 저장 직후) 묶어서 배포
        ▼
[db.samsungat.co.kr/sdp/sub/]  version.js · sub_index.js · sub_policy.js · sub_cards.js · sub_plans_*.js
        │  상품 페이지가 5분마다 version.js 를 보고 바뀌었으면 새로 받음
        ▼
[고도몰 상품상세]  goods/_sub_tab.html (설정 몇 줄) ── /data/js/sub/sub_tab_<판>.js · .css (화면 코드)
```

- 고도몰에는 **설정 파일 1개 + 화면 코드 2개**만 있습니다. 데이터는 전부 데이터센터에서 옵니다.
- 데이터센터가 잠시 안 되더라도 고도몰 `/data/js/sub/` 에 둔 예비 사본으로 계속 보입니다(최신은 아닐 수 있음).

## 3. 잘 나오는지 확인하는 법 (3분)

1. 상품 페이지 주소 뒤에 `&subtab=on` 을 붙여 엽니다. 예)
   `https://samsungsh.co.kr/goods/goods_view.php?goodsNo=1000000724&subtab=on` (에어드레서 · 일시불보다 싼 경우)
   `https://samsungsh.co.kr/goods/goods_view.php?goodsNo=1000001048&subtab=on` (AI콤보 · 일시불이 싼 경우)
   ※ 테스트 모드(`enabled: 'test'`)에서는 `&subtab=on` 이 있어야만 보입니다. 오픈(`true`) 후에는 붙이지 않아도 보입니다.
2. 상품명 아래 **[일시불] [구독]** 탭이 있는지, 구독 칸에 "N년 총 ○○○원 / 월 ○○원"이 나오는지 봅니다.
3. 구독 칸을 누르면
   - 일시불보다 싼 상품: "선택한 혜택 적용 시 일시불 구매보다 ○○○원 저렴해요" + 일시불가(취소선) → N년 구독 총액
   - 그렇지 않은 상품: "월 ○○원" 크게 + "N년 구독 총액 · 일시불" 한 줄
   - 그 아래 "기준: 6년 약정 · 무상수리 · **삼성카드** 적용" — 이 카드 이름이 관리자 [기본 기준]의 카드와 같아야 합니다.
   - [조건별 구독가 확인하기] 를 누르면 약정·케어·선납·카드를 바꿔 볼 수 있습니다.
4. 맨 아래 [시흥몰 가격 확인하기] [구독 문의하기] 버튼. 문의하기를 누르면 상담 신청 페이지가 열리고 모델명이 채워져 있어야 합니다.

**안 떠야 정상인 경우**
- 카테고리가 **구독상품**(코드 012로 시작)인 상품 — 이미 구독 전용 상품이라 탭을 띄우지 않습니다.
- DPS 요금표에 없는 모델 — 구독 칸이 없이 일시불만 보입니다.

**바꾼 값이 안 보일 때** — 저장 후 10분을 기다렸는지, 브라우저 새로고침(Ctrl+F5)을 했는지 확인합니다. 그래도 안 보이면 `https://db.samsungat.co.kr/sdp/sub/version.js` 를 열어 `SUB_VER` 의 두 번째 조각(정책 판, 예 `261029-1411`)이 관리자 화면 위쪽 "정책 판"과 같은지 봅니다. 다르면 아직 배포 전입니다.

## 4. 켜기 · 끄기 · 테스트 모드 (고도몰에서 하는 유일한 일)

고도몰 관리자 › 디자인 관리 › 스킨 디자인 수정 › `designbook_air_RES` › `goods/_sub_tab.html` 을 열면 위쪽에 이런 줄이 있습니다.

```
enabled: 'test',    /* ★ 'test': 주소에 ?subtab=on 붙인 사람만 보임 → 검증 후 true 로 오픈, 문제 시 false */
```

| 값 | 뜻 |
|---|---|
| `'test'` | 주소에 `&subtab=on` 을 붙인 사람만 보임 (지금 상태) |
| `true` | 모든 고객에게 보임 (오픈) |
| `false` | 아무에게도 안 보임 (문제 생겼을 때 즉시 끄기) |

따옴표와 쉼표를 그대로 두고 **그 한 줄만** 고쳐 저장하면 바로 반영됩니다.
같은 파일의 `consultUrl · tel · defaultCard · defaultTier` 는 **비워 두는 것이 정상**입니다 — 비어 있어야 데이터센터 [기본 기준]의 값을 씁니다. 채우면 이 스킨만 그 값으로 고정됩니다.

`goods_view.html` 에는 맨 아래 `includeFile('goods/_sub_tab.html')` 한 줄만 들어 있습니다. 그 줄을 지우면 탭 자체가 사라집니다(되돌리려면 다시 넣기).

## 5. 데이터센터 관리자에서 값 바꾸기

주소: `https://db.samsungat.co.kr/admin.html` → 왼쪽 **품목** → 아래로 내려 **구독 혜택 정책** 카드.

- **기본 기준 · 상담 연락처**: 처음 선택되는 제휴카드(목록에서 고름) · 실적 구간(카드표의 구간 이름 그대로, 예 `30만↑`) · 상담 신청 주소 · 전화 → [저장]
  - 카드·구간을 바꾸면 상품상세 탭 머리의 금액, "카드 적용 시 최대 ○○원 저렴" 배지, 구독센터 목록의 "카드 할인 시" 금액이 모두 그 기준으로 다시 계산됩니다.
  - 전화를 비우면 전화 버튼이 빠집니다. 상담 주소는 `/` 또는 `https://` 로 시작해야 저장됩니다.
- **자동납부 할인 · 선납**: 비율은 % 로 적습니다(5 → 5%).
- **제휴카드 유의사항·노출 기간**: 기간을 적으면 그 기간에만 카드가 보이고, 숨김을 켜면 바로 빠집니다. 카드 금액표 자체(구간별 할인액)는 SDP 판에서 옵니다.
- **행사 문구**: 기간·대상 품목/모델을 정하면 그때만 혜택 목록에 한 줄로 나갑니다(금액 계산에는 안 들어감).
- 저장하면 "10분 안에 배포됩니다" 안내가 뜨고, 화면 위 "마지막 배포" 시각이 바뀌면 끝입니다. 누가 언제 무엇을 바꿨는지는 맨 아래 **최근 바뀐 것**에 남습니다.

매장 화면(`store.html` › 견적서 › 구독 혜택 안내)에서는 점장님·대표님이 **행사 문구·카드 유의사항**만 고칠 수 있고, 기본 카드·전화는 보기만 됩니다.

## 6. 화면 코드를 새로 올려야 할 때 (개발 담당)

고도몰 CDN이 파일을 1시간 캐시하므로 **같은 이름으로 덮어쓰지 않고** 판을 붙인 새 이름으로 올립니다.

1. 데이터센터 저장소에서 `sdp/sub/sub_tab.js` · `sub_tab.css` 를 고치고 커밋·푸시 (구독센터는 이것으로 바로 반영).
2. 고도몰 관리자 › 디자인 › **웹FTP** › `data/js/sub/` 에 `sub_tab_<판>.js` (예 `sub_tab_261029d.js`), 바뀐 경우 `sub_tab_<판>.css` 업로드.
3. 웹FTP › `data/skin/front/designbook_air_RES/goods/` 에 새 `_sub_tab.html` 을 `_sub_tab_v<n>.html` 이름으로 올린 뒤,
   기존 `_sub_tab.html` → `_sub_tab_v<이전>_<날짜>.html` 로 이름변경, 새 파일 → `_sub_tab.html` 로 이름변경 (덮어쓰기 대신 바꿔치기 — 되돌리기 쉽게).
   새 `_sub_tab.html` 안의 `<link href>` · `<script src>` 파일 이름과 `uiVer` 를 새 판으로 맞춥니다.
4. 상품 페이지 소스에서 `sub_tab_<새판>.js` 가 보이면 끝. 문제가 있으면 3번의 이름변경을 반대로 하면 1분 안에 되돌아갑니다.

지금 고도몰에 있는 파일 (2026-10-29 기준)
- `goods/_sub_tab.html` = v8 (`sub_tab_261029d.js` · `sub_tab_261029c.css` · `enabled: 'test'`)
- 백업: `_sub_tab_v3_1028.html` · `_sub_tab_v5_1029.html` · `_sub_tab_v6_1029.html` · `_sub_tab_v7_1029.html`
- `data/js/sub/`: `sub_tab_261029d.js`(현재) · `sub_tab_261029c.css`(현재) · 이전 판 `sub_tab_261029b.js/.css` · `sub_tab.js/.css`(10-29 10:31 예비 사본)

## 7. 자주 묻는 것

- **구독탭 금액과 구독센터 금액이 다르다?** 둘 다 같은 `sub_index.js · sub_policy.js` 를 읽습니다. 한쪽이 옛 판을 캐시했을 가능성이 크니 Ctrl+F5. 그래도 다르면 상품 페이지의 `uiVer`(고도몰 화면 코드 판)가 저장소 최신과 다른지 개발 담당에게 확인 요청.
- **특정 모델만 구독가를 바꾸고 싶다?** 관리자 › 품목 › 구독 요금 직접 관리 (기간 지정 가능, 끝나면 자동 복귀).
- **특정 상품에서 탭을 숨기고 싶다?** 그 상품의 대표 카테고리를 구독상품(012)으로 두거나, `_sub_tab.html` 의 `onlyGoods` 에 시범 상품번호만 적어 그 밖의 상품을 숨깁니다.
- **데이터센터가 멈추면?** 상품 페이지는 고도몰 `/data/js/sub/` 의 예비 사본으로 계속 뜹니다. 예비 사본은 데이터센터 복구 후 개발 담당이 한 번 갱신합니다.
