코드는 숫자 4자리, 중복 불가. 담당자가 매장 화면에서 코드를 넣으면 판매·상담의 담당자가 자동으로 본인이 됩니다. 비활성으로 바꾸면 로그인만 막히고 기존 원장 기록은 그대로 남습니다.

계정 · 권한 아이디 로그인 가능

admin 삭제·일괄 적재·설정 · user 조회·입력·승인. 실번호 표시는 권한이 아니라 화면 토글이며 켤 때마다 감사로그에 남습니다.
