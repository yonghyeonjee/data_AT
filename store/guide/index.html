1시작하기 · 잠그기

  1. 주소를 열고 담당자 코드 4자리를 누릅니다. 4자리가 채워지면 바로 확인됩니다.
  2. 이름이 뜨면 시작입니다. 코드는 이 기기에 기억되므로 다음부터는 잠금 해제만 하면 됩니다.
  3. 자리를 비울 때는 왼쪽 메뉴 아래 잠그기. 코드를 다시 넣으면 하던 자리에서 이어집니다.
  4. 글자가 작으면 메뉴 아래 글자 크기에서 중간·크게로 바꾸세요. 기기마다 따로 기억합니다.
코드를 5번 틀리면 15분 동안 잠깁니다. 3번째부터 남은 횟수가 표시됩니다. 급하면 관리자에게 풀어 달라고 하세요.

2화면 구성과 배지

왼쪽 메뉴(폰에서는 아래 탭과 ☰ 서랍)가 세 묶음입니다.

상담홈 · 상담 · 상담 입력 · 견적서 · 내 고객 · CRM
매장판매 입력 · 일 마감(월 마감 포함)
현황처리현황 · 판매현황

일 마감은 필요할 때 쓰면 됩니다. 안 했다고 홈이나 배지로 재촉하지 않습니다. 온라인사업부 계정에는 재고 · 주문서 · 온라인 메뉴가 더 보이는데 매장에서는 쓰지 않아 이 안내에서는 다루지 않습니다.

메뉴 이름 옆 숫자 배지는 내가 손대야 할 건수입니다. 빨간 배지는 지난 콜백·미배정처럼 늦은 것, 흰 배지는 대기 중인 건수입니다. 점장님·대표님에게만 보이는 칸은 제목 옆에 "점장님 · 대표님만 보입니다"라고 적혀 있습니다.

3상황 1 · 온라인 문의가 들어왔을 때

홈페이지 견적문의 · 구독 문의 · 소모품/렌탈 문의 · 카카오채널로 들어온 건은 자동으로 상담 표에 쌓이고 담당자가 정해집니다. 잔디 알림도 같이 옵니다.

문의 접수→자동 배정→내 상담에 뜸→연락 · 상태 바꾸기→콜백 · 견적서→구매 확정
  1. 잔디 알림이 오고, 홈 흐름 띠의 새 문의 숫자가 올라갑니다. 새 문의 = 나에게 배정됐는데 아직 통화 안 한 건입니다. 어제 밤에 온 것도 통화 전이면 여기 있습니다. 아래 작은 글씨 "오늘 +n"이 오늘 들어온 수입니다.
  2. 상담 탭을 열면 미완료 칩이 켜진 채 내 건이 급한 순으로 나옵니다. 연락 전 = 아직 통화 안 한 문의, 상담중 = 통화한 뒤입니다. 통화하면 줄을 펼쳐 상태 줄에서 상담중을 누르세요. 통화하면 흐름 띠에서 '새 문의'가 줄고 '내 상담'이 늘어납니다.
  3. 줄을 눌러 펼치고 전화로 연락합니다. 통화 뒤 상태를 상담중으로 바꾸고, 다시 연락할 시간은 콜백으로 잡습니다.
  4. 고객이 말한 내용은 펼친 곳의 메모에 남깁니다. 나중에 이 말로 찾습니다.
  5. 내 것이 아닌데 나에게 왔으면 점장님에게 말해 배정을 바꿉니다. 점장님은 상담 탭 위 전체 상담 · 배정에서 넘깁니다.
VMS · B2B(기업) 문의는 온라인사업부 박은지 프로가 맡습니다. 매장 화면에는 나오지 않고, 내가 직접 입력한 VMS 상담만 내 상담에 보입니다.

4상황 2 · 매장에 고객이 왔을 때

사려다 만 고객도 남깁니다. 그 기록이 다음 매출의 재료입니다.

  1. 홈의 ＋ 상담 입력 또는 메뉴 상담 입력. 폼은 위에서 아래로 7개 묶음이고 묶음마다 배경색이 다릅니다.
  2. 고객 묶음에서 기존 고객 찾기에 이름이나 번호 뒷자리를 넣어 보세요. 전에 온 고객이면 이력이 뜨고 연결됩니다. 처음이면 고객명 · 휴대폰을 새로 적습니다.
  3. 어떻게 들어온 문의인지 묶음에서 상담 방법(대면), 문의 채널(매장 직접 방문), 문의 유형을 고릅니다. 이때 "혹시 어디서 보고 오셨는지" 한 번 물어보고 유입경로를 고릅니다.
  4. 무엇에 관심이 있나 묶음에 관심 품목과 고객이 말한 그대로를 적습니다.
  5. 어디까지 갔나 묶음에서 상태를 고릅니다. 그 자리에서 샀으면 상담 완료 · 구매함 + 구매 제품 · 금액. 판매 입력이 함께 올라갑니다. 고민 중이면 상담중 + 콜백.
  6. 다음에 살 것이 있으면 적고, 저장. 접수번호가 뜨면 끝입니다.
DPS에 판매를 넣었다면 판매 입력 탭에도 같은 건을 1건 남깁니다. 상담에서 '구매함'으로 저장했으면 이미 들어가 있으니 두 번 넣지 마세요.

5상황 3 · 콜백 → 견적서 → 구매 확정

  1. 콜백 — 상담 줄을 펼쳐 콜백으로 날짜·시간을 잡으면 홈 콜백 약속에 시간순으로 뜹니다. 화면 어디서나 "콜백"은 이 약속을 뜻합니다. 지난 약속은 빨간색이고 메뉴 홈에 빨간 배지가 붙습니다. 통화가 끝나면 완료.
  2. 견적서 — 상담 줄의 견적서 만들기를 누르면 고객 정보가 채워진 채 견적서 페이지가 열립니다. 만든 견적서는 견적서 탭에 뜨고 보내기로 고객 링크를 만듭니다.
  3. 구매 확정 — 고객이 결정하면 상담 줄의 구매 확정. 판매 입력 화면이 견적 금액까지 채워진 채 열리니 확인하고 저장합니다.
  4. 배송·설치가 끝나면 판매 입력 탭 아래 확정 대기에서 판매완료를 누릅니다. 이게 확정 매출입니다.
상담완료는 상담을 끝내는 것이고 판매가 아닙니다. 샀으면 반드시 구매 확정이나 구매함으로 남기세요. 성공률 통계가 여기서 나옵니다.

6상황 4 · 지난 상담을 찾을 때

"지난달에 왔던 세탁기 고객인데…" 같은 상황입니다. 세 군데 중 아무 데서나 찾습니다.

어디서무엇을이럴 때
홈 [찾기]이름 · 번호 뒷자리 · 제품명으로 담당자 전체 상담 + 내 견적서누가 맡았는지 모를 때. 남의 건은 담당 이름만 보이고 전화는 걸 수 있습니다.
상담 탭 · 찾기 · 기간내 상담을 검색어 + 기간 + 상태 칩으로내가 맡았던 건. 폰에서는 ⌕ 찾기 · 기간을 눌러 펼칩니다. 완료된 건은 완료 또는 전체 칩.
내 고객 탭고객 이름으로 찾아 줄을 펼치면 상담 · 구매 이력 전부그 고객과의 모든 기록을 한 번에 볼 때. 마지막 상태 · 상담 횟수 · 지난 날짜가 줄에 보입니다.
안 보이면 먼저 기간을 전체, 칩을 전체로. 2026년 9월 전 오래된 미완료는 확인완료로 정리돼 있어 전체에서만 보입니다.

7홈 — 오늘 챙길 것

들어오자마자 오늘 할 일이 보이는 자리입니다. 위에서 아래로 읽으면 됩니다.

흐름 띠

새 문의→배정→내 상담→콜백→견적서→구매 확정

칸은 내 일의 단계입니다. 새 문의 = 나에게 왔는데 아직 통화 안 한 건(언제 들어왔든), 아래 작은 글씨 "오늘 +n"이 오늘 들어온 수. 내 상담 = 통화한 뒤 진행 중(보류 포함). 그다음 콜백 · 견적서 · 구매 확정입니다. 각 단계에 지금 몇 건이 걸려 있는지 보여줍니다. 숫자를 누르면 그 목록으로 갑니다. 상담 한 건은 이 순서로 흘러가고, 마지막 구매 확정이 되면 판매 입력까지 자동으로 채워집니다.

챙길 것

미배정 문의(점장), 지난 콜백처럼 지금 손대야 하는 것만 띄웁니다. 아무것도 없으면 이 칸은 비어 있습니다.

찾기

고객 이름·전화 뒷자리·제품명을 넣으면 상담과 견적서를 한 번에 찾습니다. 상담은 담당자 전체에서 찾으므로 다른 프로가 맡은 건도 나옵니다. 내 것은 상담 열기, 남의 것은 담당 이름만 보이고 전화는 걸 수 있습니다.

콜백 약속

상담 입력에서 콜백 예정을 남기면 시간순으로 뜹니다. 전화로 바로 걸고, 끝나면 완료. 지난 약속은 빨간색입니다.

우선 순위 상담 (점장님 · 대표님)

누구부터 챙길지 볼 때 봅니다. 14일 · 30일은 그만큼 손 안 댄 건수입니다. 이름을 누르면 상담 탭에서 그 담당자 건만 봅니다.

8상담 — 내 상담 처리

찾고, 상태를 바꾸고, 견적서를 열고, 구매로 넘기는 일이 전부 여기서 됩니다.

  1. 줄을 누르면 펼쳐지고 세 줄이 나옵니다. 첫 줄은 하는 일 — 전화 콜백 견적서 만들기 구매 확정. 둘째 줄은 상태 — 연락 전 · 상담중 · 보류 · 완료 · 거절 중 지금 상태가 켜져 있고, 다른 걸 누르면 그 상태로 바뀝니다. 아래 한 줄 설명이 지금 상태의 뜻입니다. 셋째 줄은 새 상담 · 넘기기, 그리고 떨어진 자리에 삭제.
  2. 폰에서는 찾기·기간 도구가 접혀 있어 목록이 먼저 보입니다. ⌕ 찾기 · 기간을 누르면 펼쳐집니다.
  3. 상담완료는 이 상담을 끝내는 것이고, ＋ 새 상담은 이 건은 그대로 두고 같은 고객으로 상담을 하나 더 적는 것입니다. 두 번째 방문·재통화처럼 내용이 새로 생기면 새 상담, 더 할 게 없으면 상담완료입니다.
  4. 목록은 급한 순입니다. 지난 콜백이 맨 위, 그다음 오래 방치된 순서. 14일·30일 뱃지가 붙으면 그만큼 손 안 댄 건입니다.
  5. 위 칩으로 미완료 보류 완료 전체를 고릅니다. 칩은 하나만 켜집니다.

상태의 뜻

상태뜻
연락 전아직 통화 안 한 문의. 온라인·방문 접수는 전부 이 상태로 들어옵니다. 통화했으면 상태 줄에서 상담중. 펼친 줄의 상태 아래 한 줄이 그 뜻을 늘 설명합니다.
상담중연락했고 진행 중. 콜백을 잡아 두면 홈에 뜹니다.
보류고객 사정으로 멈춤. 잊지 않도록 목록에는 남습니다.
완료상담이 끝남. 상담 완료 ≠ 판매입니다. 샀으면 아래 '구매함'으로.
구매함구매로 이어짐. 금액을 넣으면 판매 입력에 자동으로 올라갑니다.
확인완료2026년 9월 전에 남아 있던 오래된 미완료를 정리해 둔 자리. 실제 처리 여부는 모르는 상태라 미완료도 완료도 아닙니다. 전체에서만 보입니다.

전체 상담 · 배정 (점장님 · 대표님)

미배정 건을 배정하거나 담당을 바꿉니다. 목록은 문의 온 날 순이고, 폰에서는 ⌕ 기간 · 출처를 눌러 조건을 펼칩니다. 자세한 것은 14장.

9상담 입력

사려다 만 고객이 곧 가망고객입니다. 여기 쌓인 상담이 다음 매출의 재료가 됩니다.

  1. 입력 칸은 언제·누가 → 고객 → 어떻게 들어온 문의인지 → 무엇에 관심이 있나 → 어디까지 갔나 → 다음에 살 것 → 메모·약속·동의 순서로 묶여 있고, 묶음마다 배경색이 번갈아 있습니다. 위에서 아래로 채우면 됩니다.
  2. 문의 채널을 고를 때 "혹시 어디서 보고 오셨는지" 한 번 물어봐 주세요. 유입경로는 고른 채널의 경로가 위에 올라옵니다.
  3. 관심품목 · 유입경로는 꼭 적습니다. 유입경로별 실매출 계산의 키입니다. 품목을 모르면 알 수 없음을 고르고, 고객이 한 말은 상세 관심 품목에 그대로 적습니다.
  4. 고객명·번호는 동의받은 경우만 넣습니다. 번호 뒷자리 4자리로 기존 고객이 찾아집니다.
  5. "내일 2시에 전화 주세요"는 콜백 예정에 넣으세요. 시스템이 기억하고 홈에 띄웁니다.
  6. 상담 상태는 버튼 네 개뿐입니다. 상담중(기본) · 보류 · 완료(안 삼) · 구매함. 거절은 상담 목록에서 처리합니다.
  7. 구매함을 고르고 제품과 금액을 넣으면 판매로 함께 올라갑니다. 판매 입력을 따로 하지 않아도 됩니다.
  8. 팔고 끝이 아니라 다음에 살 제품을 적어 두면 계속 이어집니다.

10견적서 · 고객에게 보내기

  1. 견적서는 홈페이지 견적서 발행 ↗에서 만듭니다. 상담 줄의 견적서 만들기를 누르면 고객 정보가 채워진 채 열립니다.
  2. 만든 견적서는 견적서 탭에서 검색어·기간으로 찾습니다.
  3. 보내기를 누르면 고객용 링크가 생깁니다. 링크 복사나 카카오 · 공유로 보내세요. 문자로 보내기는 아직 개발중이라 누르면 링크만 복사됩니다. 고객은 로그인 없이 링크만 열면 되고, 링크는 기본 180일 동안 유효합니다.
  4. 보낸 링크를 고객이 열어봤는지는 CRM 탭에서 봅니다.
  5. 유효기한이 지나도 견적서는 지워지지 않습니다. 고객에게는 "기한이 지났습니다"와 담당 프로님 연락처가 보입니다.

11내 고객

내가 상담하거나 판매한 고객 전부입니다. 판매·상담에 고객명과 번호를 남기면 자동으로 생기고, 따로 등록하지 않습니다.

  • 줄마다 마지막 상태(상담중 · 보류 · 상담완료 …), 상담 횟수, 마지막 상담 뒤 지난 날짜, 마지막 문의 채널과 관심 품목이 보입니다. 30일 넘게 손 안 댄 고객은 날짜가 주황색입니다. 콜백이 잡혀 있으면 콜백 대기가 붙습니다.
  • 줄을 누르면 아래로 펼쳐져 상담 이력과 구매 이력이 전부 보입니다. 펼친 곳의 ＋ 상담 입력은 그 고객으로 새 상담을 적고, 전화는 바로 겁니다.
  • 검색어(이름 · 번호 뒷자리) · 기간(마지막 상담일) · 문의 채널 드롭다운으로 좁힙니다.
  • 위 고객 찾기는 내 고객이 아니어도 찾아집니다. 다른 담당자 고객이면 담당 이름이 같이 보입니다.

12CRM

고객에게 보낼 메시지와 나에게 온 알림이 모이는 곳입니다. 지금은 알림 내역을 보고, 메시지 발송과 자동 알림은 준비 중입니다. 최근 90일.

종류무엇이 보이나
📄 견적서내가 보낸 견적서 링크. 고객이 열어봤는지, 몇 번, 마지막 언제. 안 열어봤으면 회색.
👤 배정나에게 배정되거나 넘겨받은 상담. 누가 넘겼는지.
📥 새 문의온라인 · 방문 접수로 들어와 나에게 온 문의. 아직 통화 전이면 '연락 전' 표시.
📞 콜백내 콜백 약속. 예정 · 지남 · 완료.

맨 위 (예시) 줄은 자동 알림이 붙으면 쌓이는 모양입니다. 위 칩으로 종류를 골라 보고, 줄의 상담 열기 · 견적서로 바로 갑니다. 줄마다 메시지 보내기가 있지만 문자 발송은 아직 개발 전이라 누르면 안내만 뜹니다. 템플릿(견적서 링크 · 콜백 안내 · 감사 메시지)과 함께 붙을 예정이고, 그때부터 견적서 유효기한 안내 · 콜백 당일 안내 같은 자동 알림도 여기서 나갑니다.

13판매 입력 · 일 마감 · 월 마감

한 줄로 이어집니다: 상담에서 구매함 + 제품 · 금액 → 판매 입력에 자동 등록 → 일 마감에 그날 숫자가 자동으로 채워짐 → 일일 업무 텍스트 복사 → 월 마감에 달로 모임.

구매함→판매 입력→일 마감→일일 업무 텍스트→월 마감

판매 입력

DPS 입력 직후 같은 자리에서 1건씩 남깁니다. 필수는 상품명 · 판매가 · 구분 · 판매일 4개. 상담에서 '구매함'으로 저장했으면 이미 들어와 있으니 두 번 넣지 마세요. 배송·설치가 끝나면 아래 확정 대기에서 판매완료. 그게 확정 매출입니다.

일 마감

  1. 날짜를 고르면 그날 판매 입력이 구분 · 프로별로 자동으로 채워집니다. 숫자가 맞으면 마감 저장.
  2. 저장하면 바로 아래 일일 업무 텍스트가 만들어집니다. 복사해서 일일 보고 카톡·메일에 붙여 넣으면 됩니다.
  3. 안 한 날은 탭 안에 조용히 표시될 뿐, 홈 알림이나 배지로 재촉하지 않습니다. 필요할 때 하면 됩니다.

월 마감

일 마감 탭 맨 아래. 달을 고르면 저장된 일 마감이 날짜별 표(일시불 · 구독 · 직판 · 환불 · 순매출)와 합계로 모이고, 월 보고 텍스트 복사로 월 보고를 붙여 넣습니다. 전체로 바꾸면 매장 전체와 프로별 합계가 보입니다.

14현황 — 처리현황 · 휴가 · 판매현황

처리현황

문의가 얼마나 들어와서 얼마나 구매로 이어졌는지. 일 · 월 · 연으로 보고, 내 것 · 전체를 고릅니다. 삭제한 상담은 빠지고, 확인완료는 문의 수에는 들어가되 완료·전환에는 들어가지 않습니다.

휴가 (점장님 · 대표님)

월 달력에 담당자별 색 칩으로 보입니다. 날짜를 누르면 창이 떠서 누구 · 시작일 · 종료일 · 메모를 넣고 [추가]합니다. 휴가 중인 담당자는 자동 배정에서 빠지고 다음 사람에게 갑니다. 이미 배정된 건은 그대로이니 필요하면 상담 탭에서 넘기세요.

판매현황 · 보고용 텍스트

매장에서 입력한 판매를 일별 · 주별 · 월별, 담당 프로님별로 봅니다. 보고용 텍스트 복사로 일일보고를 바로 붙여 넣을 수 있습니다.

17문제가 생겼을 때

이런 때이렇게
코드를 넣었는데 "서버 응답이 늦습니다"서버가 잠깐 바쁜 것입니다. 화면이 알아서 두 번 더 시도하고, 그래도 안 되면 코드는 그대로 둔 채 알려줍니다. 10초쯤 뒤 시작하기를 다시 누르세요. 그래도 안 되면 새로고침.
"서버에 연결하지 못했습니다"인터넷 연결을 확인하고 새로고침. 매장 와이파이가 끊겼을 때 자주 납니다.
"등록되지 않은 담당자 코드입니다"코드를 다시 확인하세요. 5번 틀리면 15분 잠깁니다. 코드를 모르면 관리자에게.
화면이 이상하게 겹치거나 버튼이 안 눌림메뉴 아래 새로고침. 입력 중이던 내용은 저장 전이면 사라지니 먼저 저장하세요.
저장을 눌렀는데 목록에 안 보임기간 바가 7일 같은 짧은 기간으로 되어 있지 않은지, 조건 칩이 켜져 있지 않은지 보세요. 전체로 두면 다 보입니다.
내 상담이 아닌 게 배정됨 · 담당을 바꿔야 함점장님에게 요청하면 상담 탭의 배정에서 넘깁니다. 넘긴 기록은 상담에 남습니다.
실수로 삭제 · 되돌리고 싶음삭제한 상담은 상담 탭 휴지통에서 7일 안에 직접 되살릴 수 있습니다. 7일이 지나면 점장님·대표님에게 요청하세요.
그 밖의 문제는 온라인사업부에 화면 사진과 함께 알려주세요. 무엇을 눌렀는지, 몇 시쯤인지가 있으면 빨리 찾습니다.
