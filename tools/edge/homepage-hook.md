# 홈페이지 문의 웹훅 연동 안내 (삼성스토어 시흥 데이터센터)

홈페이지 견적문의(개인·사업자)가 등록될 때, **지금 잔디로 보내시는 웹훅과 같은 요청을 아래 주소로도 한 번 보내 주시면** 됩니다.
데이터센터가 상담으로 저장하고 담당자를 자동 배정한 뒤 잔디 알림도 보냅니다.

## 주소

```
POST https://wdahskrcpjooqhwwxjiu.supabase.co/functions/v1/homepage-hook?k=<키>
```

- `<키>` 는 따로 전달드립니다. **서버에서 호출해 주세요** (브라우저 자바스크립트에서 부르면 키가 노출됩니다).
- 키는 주소 대신 헤더 `x-dc-key: <키>` 로 주셔도 됩니다.

## 보내는 형식 — 아래 중 아무거나

1. **잔디 웹훅과 같은 JSON** (그대로 복사해서 주소만 바꾸셔도 됩니다)
   ```json
   {"body":"[홈페이지 견적문의] 새 글",
    "connectInfo":[{"title":"성함","description":"홍길동"},
                   {"title":"연락처","description":"010-1234-5678"},
                   {"title":"희망품목","description":"냉장고, 에어컨"}]}
   ```
2. **항목 이름 그대로의 JSON** — `{"성함":"홍길동","연락처":"010-1234-5678","희망품목":["냉장고","에어컨"]}`
3. **폼 전송** — `application/x-www-form-urlencoded` 또는 `multipart/form-data` (첨부파일은 파일 이름만 기록됩니다. 링크를 주시면 더 좋습니다)
4. **글 한 덩어리** — `성함: 홍길동` 처럼 `항목: 값` 줄이 있으면 읽습니다

## 담아 주실 항목

성함 · 연락처 · 방문경로 · 구매옵션 · 아파트명 · 희망품목 · 제품모델명 · 상담방법 · 첨부파일 · 문의내용
(사업자 문의면 `구분: 사업자` 를 함께 주세요. 게시글 번호가 있으면 `게시글번호` 로 주시면 같은 글을 두 번 보내도 한 건으로 처리됩니다.)

## 응답

| 상태 | 뜻 |
|---|---|
| 200 `{"ok":true,"id":…,"handler":"담당자"}` | 저장됨 (`"duplicate":true` 면 이미 받은 글) |
| 403 | 키가 틀림 |
| 500 · 502 | 데이터센터 쪽 오류 — **1회 재시도** 부탁드립니다 (같은 글은 중복 저장되지 않습니다) |

## 연결 확인 (저장되지 않음)

주소 끝에 `&dry=1` 을 붙여 보내면 저장하지 않고 **읽은 결과만** 돌려줍니다. 브라우저로 주소를 열면(GET) 키가 맞는지만 확인합니다.
