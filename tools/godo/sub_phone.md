# 구독 문의 페이지 — 번호 검증 · 번호 안내 창 · 카카오 채널 요청 (SUB v1.7.3 ~ v1.7.5 · mvp_307)

고도몰 디자인 페이지 `service/SamSungSubscription.html`(스킨 designbook_air_RES)에 **들어가 있는 것**을 적어 둔다. 원본은 고도몰 페이지다(편집 화면 [저장내용 확인] 에 판마다 남는다).
실제 주소: `https://www.samsungsh.co.kr/main/html.php?htmid=service/SamSungSubscription.html` (`&evt=simple|b2b|mobile|preorder`)

## 1. 번호 검증 — `window.samSubPhoneCheck(value, landline)` (v1.7.3)
돌려주는 값 `''` = 정상 · 그 밖 = 고객에게 보일 안내문. `landline=true` 면 유선(0으로 시작 9~11자리)도 받는다 — 사업자 폼(B2B · 렌탈 · 소호)만.
1. 형식: 휴대폰 `01[016789]` + 7~8자리
2. 앞 번호(010 · 지역번호) 뒤가 전부 같은 숫자(0000-0000)거나 1씩 오르내림(1234-5678 · 8765-4321 · 3456-7890)
3. 010 바로 뒤가 0 · 1 — 통신사에 배정된 적 없는 대역(1234-1234 · 1212-1212 · 0000-1111 이 다 여기). 고객 010 번호 76,913개 중 17개뿐이고 전부 가짜 · 오타였다
4. 휴대폰 앞 4 · 뒤 4자리가 둘 다 같은 숫자거나 연속(5555-6666 · 7777-4567)

막지 않는 것: 2580-2580 · 2424-2424 처럼 앞뒤가 같기만 한 번호(실제로 쓰는 번호) · 유선 대표번호의 3 · 4번 규칙.
넣은 곳(전부 fetch · Turnstile 앞, 옛 형식 검사보다 먼저): 일반 · 자급제 `samSubSubmitForm` · 간편 `simple-form` · 렌탈 `r-submit` · B2B `b2b-form` · 소호 `s-form`.
**시험할 때**: 이름 '테스트' + 1234-1234 는 이제 페이지에서 막힌다. 이름을 '테스트' 로 하고 실제 번호를 쓴다(서버는 이름으로 테스트를 가른다).

## 2. 번호 안내 창 — `window.samSubPhoneNotice(msg, focusEl, hint)` (v1.7.4)
브라우저 기본 알림 대신 페이지 안 창. [번호 다시 입력하기](닫고 번호 칸으로) · [📞 031-8042-3166 전화하기](`tel:`) · [💬 카카오톡 채널로 문의](`https://pf.kakao.com/_NcxjaC/chat`). Esc · 바깥 클릭으로도 닫힌다.
번호 말고 다른 안내(제품 미선택 · 성함 누락 · 동의)는 아직 브라우저 기본 알림이다 — 전부 바꾸려면 봇 확인 블록의 `window.alert` 감싸기('일시적인 오류' 한 번 건너뛰기)와 같이 손봐야 한다.

## 3. 카카오 버튼 → 잔디 '카카오 채널 확인 필요' · 순번 배정 — `window.samSubKakaoPing(focusEl)` (v1.7.5)
안내 창의 카카오 버튼을 누르면(화면당 한 번) `fn_kakao_request` 를 Supabase REST 로 직접 부른다(GAS · 시트 안 거침).
- 싣는 것: 접수 화면 종류 · 고른 제품 · (개인정보 동의 체크가 있을 때만) 성함 · 상호 · 지역 · 메모 · 주소의 utm · `cid`(탭마다 한 번 만든 값). 번호는 안 싣는다.
- 사람 확인: 봇 확인 블록이 내어 주는 `window.samBotPass()`(→ `{t, st, ms, human}`). **`tools/godo/sub_turnstile.html` 을 다시 붙일 때 이 묶음이 빠지면 카카오 알림이 조용히 안 나간다.**
- 서버: 상담 한 줄(채널 카카오채널 · 번호 없음) + 잔디 CRM 방 카드. **담당은 비워 넣어 구독 문의와 같은 순번표가 배정**한다(마지막 배정자 다음 · 휴무자 건너뜀). 사람 확인 실패 · 10분 5건 넘음은 숨김(순번 안 돎 · 카드 없음). 이름 '테스트' 는 테스트 방 카드 · 순번 안 돎.
- 담당자 화면: 잔디 카드의 [이 문의 상담 입력하러 가기] 로 열면 맨 위에 [카카오 채널로 이동](채널 채팅 관리자).

## 고도몰에서 고칠 때
- 편집기 전체를 다시 치지 말고 원문에서 지점 개수를 확인한 뒤 부분 치환한다.
- 여는 중괄호 뒤에는 공백 · 줄바꿈(정규식 `{7,8}` 는 됨) · `'x.js'` 꼴 문자열 금지 · 주석에도 중괄호 템플릿 태그를 적지 않는다.
